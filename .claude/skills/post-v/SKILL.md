# /post-v - запланировать ролик в Instagram

Ролик ставится в отложенную публикацию на https://www.instagram.com/scheduled_content/ от аккаунта @const_proxima. Браузер - Яндекс Браузер пользователя: отдельное окно-профиль PostV с портом отладки 9222, в него перенесен вход из основного браузера. Управление - puppeteer-core из `engine/node_modules`, проверка скриншотов - Jev (TypeSafe, ключ `TYPESAFE_KEY` в `.env`). Ключ и пароль в чат не выводить и не спрашивать.

## Когда запускать

- `/post-v` или `/post-v N`.
- Пользователь посмотрел готовый ролик и пишет «выложи», «пуш» или «выкладывай» - это и есть подтверждение публикации, переспрашивать не нужно. Ролик - тот, о котором шла речь (обычно последний собранный `/new-v`).
- Если номер неясен - самый маленький номер в `video/` с готовым `output/video.mp4` и без `output/posted.json`. Назови его пользователю в ответе.

## Что нужно в папке ролика

`video/N-slug/output/`: `video.mp4`, `cover.jpg`, `summary-inst.txt` (подпись, до 2200 символов). Если чего-то нет - остановись и скажи, чего не хватает. `posted.json` уже есть - ролик запланирован, повторно не ставить (только если пользователь прямо просит, флаг `--force`).

## Расписание

- Три ролика в день по местному времени: 06:00, 08:00, 12:00. Так же в следующие дни.
- Слот - следующий после последнего запланированного поста (после 06:00 - 08:00 того же дня, после 08:00 - 12:00, после 12:00 - 06:00 следующего дня). Скрипт читает календарь на 10 недель вперед и `posted.json` всех роликов. Если ничего не запланировано - ближайший слот, до которого больше 25 минут.
- Своя дата, если пользователь назвал: `--at "2026-10-25 06:00"`. Instagram принимает время не раньше чем через 20 минут.

## Шаги

1. Браузер (из корня проекта):
   ```
   zsh .claude/skills/post-v/scripts/yandex-debug.sh
   ```
   Окно PostV открывается рядом с обычным браузером. Если скрипт публикации остановился с «Instagram просит вход» (код 4) - `yandex-debug.sh --fresh`: закрывает окно PostV, заново копирует вход из основного Яндекс Браузера и открывает окно. Если и после этого вход не появился - попроси пользователя войти в Instagram в основном Яндекс Браузере.
2. Публикация:
   ```
   node .claude/skills/post-v/scripts/post.mjs N
   ```
   Скрипт делает то же, что человек:
   - «Запланировать публикацию контента» -> загрузка `video.mp4`;
   - «Обрезать»: значок размера -> «Оригинал» -> «Далее»;
   - «Редактировать»: «Фото обложки» -> «Выбрать на компьютере» = `cover.jpg` -> «Далее»;
   - «Новое видео Reels»: подпись из `summary-inst.txt` (без перевода строки в конце - Enter после хэштега выбирает подсказку Instagram и подменяет тег; подпись сверяется с файлом символ в символ), «Добавить метку ИИ» - вкл, «Запланируйте публикацию контента» - вкл, дата, время;
   - «Запланировать» -> ждет «Видео Reels запланировано.» -> «Готово»;
   - пишет `output/posted.json` (дата, время, аккаунт).

   Jev проверяет скриншотом каждый шаг окна (crop, edit, details, done) и перед публикацией - время, дату, оба переключателя и отсутствие красной ошибки. Скриншот формы сохраняется в `output/post-form.png`. Любое расхождение - остановка без публикации.
3. После успешной публикации (есть `posted.json`, не после `--dry`) удали все черновики ролика, это решение пользователя. В `output/` остаются только `video.mp4`, `cover.jpg`, `summary-inst.txt`, `share-copy.txt`, `posted.json`; в папке ролика - исходники (`v.html`, `img/`, `three.mjs`, озвучка, `words.json`, `субтитры.txt`, `music/`, `video.json`). Папка `work/`, превью, кадры ревью, `plan.md`, `review.md`, отчеты `pipeline-*` и скриншот формы удаляются:
   ```
   cd video/N-slug && rm -rf work && find output -mindepth 1 -maxdepth 1 ! -name video.mp4 ! -name cover.jpg ! -name summary-inst.txt ! -name share-copy.txt ! -name posted.json -exec rm -rf {} +
   ```
4. Пробный прогон без публикации: `--dry` (форма заполняется и проверяется, окно закрывается с «Удалить»). Делать, если пользователь просит «проверь» или после правок скрипта.

## Если остановился

Скрипт пишет «СТОП: ...» и путь к скриншоту `/tmp/postv/step.png`. Посмотри скриншот. Пока не было «Видео Reels запланировано», ничего не опубликовано; окно Instagram остается открытым - закрой его крестиком и «Удалить», затем запусти заново. Ручная отладка - `scripts/pv.mjs` (`shot`, `eval`, `click "<текст>"`, `xy x y`, `upload`, `type`, `key`), проверка скриншота - `scripts/jev.mjs <png> '<вопросы>'`.

Не кликай по фону вокруг окна: это открывает «Отменить публикацию?».

## Итог для пользователя

Коротко: какой ролик, на какую дату и время запланирован, что подтвердил Jev, путь к `output/posted.json`. Если что-то пошло не так - что именно и опубликовано ли что-то.
