# Как делается ролик

Карта процесса от сценария до публикации: что делается на каждом шаге, какой командой, где лежит результат и что проверяется. Правила стиля и текста - `AGENTS.md`, визуальные правила и реализация - `DESIGN-SYSTEM.md`, движок - `engine/README.md`. Запуск всего - `/new-v`, публикация - `/post-v`. Для эпизодов 100-109 сначала прочитай `video/black-box/SERIES.md` (доступность - см. `AGENTS.md`): там нет озвучки и музыки, тайминги ручные, разрешены только SFX серии.

## Где что лежит

```
video/N-slug/            все про один ролик
  субтитры.txt           сценарий с тегами ElevenLabs ([sarcastic], [short pause])
  ElevenLabs_*.mp3       озвучка
  words.json             тайминги слов [[слово, начало, конец], ...]
  v.html                 сцены ролика (копия engine/templates/template.html)
  img/  three.mjs        картинки и 3D этого ролика
  music/                 трек, если есть
  work/                  черновые стоп-кадры и разовые скрипты
  output/                video.mp4, cover.jpg, summary-inst.txt, share-copy.txt, plan.md, отчеты pipeline-*
engine/                  общий движок, файлы роликов сюда не кладем
sfx/                     звуки движка, в обычных роликах отключены (noSfx:true)
video/assets/images/     мем-картинки
```

`v.html` начинается со строки `<base href="../../engine/">`: ссылки на движок считаются от `engine/` (`styles/base.css`, `runtime/engine.js`), свои файлы ролика - `../video/N-slug/img/x.jpg`.

## Шаги

| # | Шаг | Кто | Команда | Результат |
|---|---|---|---|---|
| 1 | Параметры: музыка, картинки, сценарий | пользователь | `/new-v` спрашивает | `video/N-slug/субтитры.txt`, `music/`, `img/` |
| 2 | Хук первых 3 с | агент, утверждает пользователь | - | хук в `output/plan.md`; слабая первая фраза - переписать до озвучки |
| 3 | Озвучка + тайминги | скрипт | `python3 engine/audio/tts.py video/N-slug` | mp3 + `words.json` за один запрос |
| 4 | План сцен | агент | - | таблица в `output/plan.md` |
| 5 | Верстка | агент | копия `engine/templates/template.html` -> `v.html`, обновить демонстрационные сцены по `AGENTS.md` | `v.html`, `video.json` с `duration` и `noSfx:true` |
| 6 | Проверка | конвейер | `node engine/pipeline/video.mjs N --check-only` | замечания в консоли, `output/pipeline-*.json` |
| 7 | Превью правок | конвейер | `node engine/pipeline/video.mjs N --preview --from 12 --to 18` | `output/preview-12-18/video.mp4` за секунды |
| 8 | Финальная сборка | конвейер | `node engine/pipeline/video.mjs N` | `output/video.mp4`, `cover.jpg`, `pipeline-review.md` |
| 9 | Ревью | агент | смотрит кадры `output/pipeline-review/`, слушает | `output/review.md` |
| 10 | Подписи | агент | - | `summary-inst.txt` (описание + 5 хештегов), `share-copy.txt` |
| 11 | Публикация | пользователь пишет «выложи» | `/post-v` | отложенный пост в Instagram, `output/posted.json` |
| 12 | Уборка | `/post-v` | - | удаляются черновики, остаются исходники и готовый ролик |

Правки между шагами 6 и 8 проверяются только превью (шаг 7). Полную сборку делаем один раз, в конце.

## Тайминги

Источник один - `words.json`. Каждый текст на экране получает `data-in` (или `data-wd-times`) из времени своего слова.

1. `tts.py` получает тайминги вместе с голосом (ElevenLabs `/with-timestamps`). Обычно больше ничего не нужно.
2. Если `tts.py` упал по таймауту, голос уже сгенерирован и оплачен. Не повторять запрос: `python3 engine/audio/align.py video/N-slug --from-history` скачает его из истории и снимет тайминги.
3. Если голос готовый, а таймингов нет: `python3 engine/audio/align.py video/N-slug` (Forced Alignment: аудио + известный текст, секунды).
4. Whisper - только без интернета, он медленный и путает термины.

Длительность задаем явно: `duration` в `video.json` равен концу последней сцены и включает всю концовку 2.5 с. У конвейера без настройки значение по умолчанию - голос + 1.5 с; оно не гарантирует, что концовка поместится. Для нескольких голосов - реплики в `voices.json`, команда `python3 engine/audio/tts-multi.py video/N-slug`.

## Какой стиль применяется

Всегда один: пресет default, мир p5w (`<body class="p5w">`). Подключение уже есть в `engine/templates/template.html`, ничего не выбираем.

- Слои CSS в `engine/styles/`: `fonts-p5.css` (Inter + Google Sans) -> `base.css` (safe zone, сетка) -> `preset-minimal.css` -> `preset-dynamic.css` -> `p5-world.css` (белые и черные сцены, палитры, стекло на обоях).
- Сцены `.white` / `.black`, акцент `pal-*`; подряд на одном фоне до 2-3 сцен, затем смена. Шаблон содержит актуальные сцены default: wallpapers размывает отдельный фоновый слой, glass задается только смысловым акцентам через `.glass`.
- JS в `engine/runtime/`: `engine.js` (время, концовка `section.outro` с профилем, входы `data-in`) -> `preset-dynamic.js` -> `preset-minimal.js` -> `init()`. Кривые `p5-ease.js`, камера `data-camk`, переходы `data-tr`.
- Свое оформление ролика - в `<style>` внутри `v.html`. Свои классы не называть как классы движка (`.row`, `.card`, `.mut`): конвейер предупредит.

## Что проверяет конвейер

`node engine/pipeline/video.mjs N` в конце печатает строку `Checks: ...` и пишет все в `output/pipeline-review.md`.

| Проверка | Когда | Норма | Если не так |
|---|---|---|---|
| Сцены, ресурсы, safe zone, тайминги слов, ритм (`check.mjs`, `p5gaps`) | всегда | без ошибок | сборка останавливается |
| Планировка (`frame-layout.mjs`) | всегда | заполнено 50%+ (хук 70%+), цель наезда в safe zone, текст не на плашке | предупреждение |
| Классы движка в стилях ролика | всегда | нет голых `.класс{}` с именем класса движка | предупреждение |
| MP4: кодек, 1080x1920, 30 fps, длительность, звук | сборка | точное совпадение | сборка останавливается |
| Пик громкости | сборка | ниже 0 dBFS | сборка останавливается |
| Рывки (`motion-check.py`) | финал | норма проекта - 0 рывков; скрипт возвращает ошибку при >2 пиках или резких сменах | каждый пик посмотреть кадрами через ffmpeg select по номеру кадра |

Автоматика не проверяет смысл, читаемость на глаз и микс на слух. Это остается за ревью (шаг 9).

## Скорость

- Кадры снимаются параллельно в 4 Chrome (`WORKERS=1..8`, по умолчанию половина ядер, не больше 4), куски склеиваются без перекодирования. 74 с ролика - около 50 с рендера.
- Кеш этапов: изменение звука не перерендеривает кадры, изменение `v.html` не пересводит звук. `--force` пересобирает все.
- Превью - 540x960, 15 fps.

## После публикации

После подтвержденного планирования `/post-v` очищает черновики по своему `SKILL.md`, включая `work/`, превью, планы и отчеты ревью. В `output/` остаются `video.mp4`, `cover.jpg`, `summary-inst.txt`, `share-copy.txt`, `posted.json`; исходники ролика сохраняются.

## Режиссура через Scene IR

Для новых сложных сцен между планом и HTML подготовьте Scene IR: смысл, метафору,
композицию, главный объект, действия с причиной, камеру и связь со следующей сценой.
Рабочий пример - `video/12-motion-direction-demo/v.html`; контракт и подключение -
`engine/README.md`, раздел «Scene IR и композиционная режиссура».

Режим narration использует реальные wordIndex из words.json. Сначала проверьте JSON
через `node engine/checks/scene-direction.mjs v.html words.json`, затем обычный
конвейер проверит соответствие сгенерированных data-* плану. Старые HTML без IR
по-прежнему принимаются. Демонстрационный режим не подтверждает синхронизацию с голосом.

После изменений камеры проверяйте промежуточные кадры и повторный seek, а после
рендера - пики motion-check. Сохраненная safe zone не доказывает плавность движения.
