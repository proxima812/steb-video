# Studio

Локальный дашборд роликов: ассеты, раскадровка, живое демо `v.html`, правка сцен и запуск сборки.
Bun (сервер) + Vite + SolidJS. Отдельно от `engine/`: движок не меняет, только вызывает `engine/pipeline/video.mjs`.

```bash
cd studio
bun install
bun run dev      # http://localhost:5173 (Vite) + API на 4321
bun run start    # собранная версия на http://localhost:4321
```

## Что есть

- **Библиотека** - обои, аватары, картинки (общие и `img/` роликов), озвучка, музыка, звуки. Поиск, фильтр «в роликах / свободные»,
  в каких роликах используется файл, прослушивание с волной, «Скопировать» - готовый сниппет для `v.html`.
- **Ролик** - раскадровка по `<section data-s data-e>` (фон, обои, палитра, переход), демо через `window.render(t)` с голосом и музыкой,
  таймлайн со сценами и словами из `words.json`, safe zone, переключение на готовые `output/**/video.mp4`.
- **Визуальный редактор** (контракт - [docs/visual-editor.md](docs/visual-editor.md)). Черновик - полный текст `v.html`;
  каждая правка - локальная замена в тексте, остальной HTML, скрипты и свои атрибуты не меняются.
  - Выбор объекта кликом по кадру (режим «Выбор», работает и для аватаров), дерево объектов сцены,
    блокировка выбора и скрытие только в редакторе (в ролик не попадают); они идут за объектом при вставке, удалении и undo,
    а если объект удален или заменен - снимаются с подсказкой.
  - Панель «Объект»: текстовые фрагменты (вложенная разметка сохраняется, предупреждение про ё и длинное тире),
    шрифт, размеры и отступы, выравнивание, палитра, `.acc`, `.mark`, `.glass`, аватар (положение, высота, `.ring`),
    положение absolute с прижатием к safe zone, «Вместить» с предпросмотром рамки, вход/уход, id, исходник объекта.
  - Undo/redo (⌘Z / ⇧⌘Z, набор в одном поле - один шаг), превью черновика до сохранения, «До/После».
  - Сохранение ⌘S: проверка версии на диске, бэкап с уникальным именем в `work/studio-backups/`, атомарная запись.
    Правки, сделанные во время записи, остаются в черновике. Undo не переходит между роликами.
    Если файл поменяли снаружи: без правок - перезагрузка, с правками - выбор «взять с диска» или «сохранить поверх».
  - «Сцена»: время, фон, палитра, обои, приглушение камеры, галерея переходов с длительностями и предпросмотром стыка
    (цикл, 0.25x), предупреждения о повторах; правка для агента.
  - «Камера»: ключи `data-camk`, цель кликом (id добавляется сам), время по слову, пресеты, проверки норм; ключи на таймлайне.
  - «Каталог»: заголовок, текст, число, карточка/результат, сравнение, код, таблица, схема, картинка, аватар, формула
    (LaTeX, SVG делает `tex2svg.mjs`), превью на стилях движка; пресеты ролика в `work/studio-presets.json`.
    Набор компонентов движка (окно, список, таблица-строки, уведомление, кнопки, тумблеры, показатель, переключатель, клавиши;
    обычный вариант и стекло для сцен на обоях) - `src/editor/catalog-kit.ts`, стили уже в `engine/styles/p5-world.css`.
    UI-компоненты из внешних примеров (кнопка «Начать» и следующие) - `src/editor/catalog-ui.ts`, стили `engine/styles/p5-ui.css`,
    анимация от времени кадра `engine/components/p5-ui.js` (`data-press`); при вставке оба файла подключаются в `v.html` один раз.
  - «Проверка»: safe zone текущего кадра, сцены или ролика (шаг 0.5/0.2/0.1 с или «каждый кадр» + ключевые моменты,
    с камерой, без кадров переходов по умолчанию, концовка не проверяется). «Каждый кадр» - шаг 1/30 с от начала каждой
    сцены: совпадает с кадрами рендера, только если `data-s` кратно 1/30; меряется DOM превью, а не готовый mp4, поэтому
    это не гарантия для всех кадров ролика. Также потенциальные пересечения, правила исходника,
    `p5gaps`, сравнение прямого seek с последовательным проигрыванием, «Сверстать формулы».
  - Плеер: скорость 0.25/0.5/1x, цикл диапазона, покадровый шаг, номер кадра.
- **Правка для агента** - заметка к сцене (`work/studio-notes.json`), «Скопировать задачу» дает текст правки с HTML сцены.
- **Музыка** - треки из `STUDIO_MUSIC_ROOT` (по умолчанию `/Users/samgold/Desktop/музыка`, только чтение, с вложенными папками):
  поиск, прослушивание с перемоткой и длительностью. «В ролик» копирует один файл в `video/N/music/` (без перезаписи,
  одинаковый файл не дублируется) и записывает `music` в `video.json` с бэкапом. Импорт и выбор звука одного ролика идут по очереди;
  запрос со старой версией настроек получает «Настройки изменились». Без нажатия аудио роликов не меняется.
- **Рендер** - проверка, превью, превью сцены, финал; лог в реальном времени, вкладка «Сборки» со всеми запусками.

Клавиши в ролике: пробел - play/pause, ←/→ - кадр (Shift - секунда), ↑/↓ - соседняя сцена, ⌘S - сохранить, ⌘Z / ⇧⌘Z - отмена и повтор, Esc - снять выбор.

Не реализовано: перетаскивание объектов мышью в кадре, перенос совпадающих объектов между сценами (match move),
автоматическое слияние своих правок с внешними изменениями файла.

## Добавление материалов и создание

- **Ролики → Создать ролик**: название и необязательный сценарий. Номер выбирается по существующим папкам, в том числе незавершенным и вложенным сериям; 100-109 зарезервированы для «Черного ящика». Одновременные запросы получают разные номера.
- Создается отдельная папка `video/N-название/`: `v.html` на основе шаблона движка, `video.json`, `субтитры.txt`, папки `img/`, `music/`, `work/`, `output/`. Демо содержит стартовую сцену на 5 секунд и концовку на 2.5 секунды. Это черновик: сценарий не превращается автоматически в готовые сцены, голос не генерируется.
- **Библиотека → Добавить материал**: несколько файлов через выбор или перетаскивание, статус каждого файла и повторная загрузка только неудачных. До 100 МБ на файл. Изображения: PNG/JPG/WEBP/GIF/AVIF; аудио: MP3/WAV/M4A/FLAC/OGG. SVG в загрузке не принимается; существующие SVG остаются в библиотеке.
- Общие картинки сохраняются в `video/assets/images/`, озвучка в `video/assets/voices/`, музыка в `video/music/`. Старые треки из корневой `music/` также видны и доступны для прослушивания. Обои, аватары и звуки сохраняются только в общие `video/wallpapers/`, `video/avatar/`, `video/sfx/`.
- Картинки, музыка и озвучка могут сохраняться в выбранный ролик: `img/`, `music/` и корень папки ролика соответственно. Загруженная озвучка получает префикс `voice-`. Совпавшие имена получают суффикс; файлы не перезаписываются.
- **Ролик → Ассеты**: загрузка в текущий ролик, выбор озвучки и музыки, отключение музыки, поиск картинки и вставка в черновик выбранной сцены. После вставки сохранить сцену и проверить композицию в демо. Обои выбираются во вкладке «Сцена».
- Выбор звука сохраняется в `video.json` с резервной копией в `work/studio-backups/`. Существующие настройки сохраняются; конфликт с внешней правкой возвращает ошибку вместо перезаписи. Загрузка звуков не включает SFX в ролике.
- При замене озвучки необходимо подготовить `words.json` и тайминги заново по `PIPELINE.md`. Студия не выполняет выравнивание автоматически. Конвейеру нужна озвучка даже для проверки; без нее запуск из интерфейса объясняет, что нужно добавить.
- Переход между страницами, смена сцены и закрытие вкладки предупреждают о несохраненных правках. Рендер запускается после сохранения изменений. Библиотека обновляется после загрузки автоматически.

API слушает локальный `127.0.0.1`; запросы изменения с внешнего Origin отклоняются. Новые операции создания, загрузки и настройки звука проверяют выход за корень проекта, в том числе через симлинки.

Легкие проверки из `studio/`: `bun test` и `bunx --no-install tsc -p .`. Тесты файловых операций используют временные каталоги вне проекта;
тест модели исходника читает (не меняет) `video/1-design-rules-test/v.html`, если он есть. Переходы движка: `cd engine && node checks/transition-endpoints.mjs`.
