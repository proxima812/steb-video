Раунд 3. Дефект: `remapPaths` для `<p>A</p><p>A</p><p>B</p>` → `<p>A</p><p>B</p>` отображал оба прежних `A` в один
новый (`s0.0→s0.0`, `s0.1→s0.0`), поэтому скрытие, блокировка, выбор или непримененая правка исходника удаленного
близнеца переходили на оставшегося. Исправлено в `src/editor/remap.ts`: путь переносится, только если оба крайних
положения измененного диапазона дают один объект, иначе только по точному HTML, единственному до и после; два прежних
объекта никогда не получают один новый. Неоднозначность сбрасывает состояние (существующий тост), уникальные объекты
сохраняют привязку. Цена консервативности: при удалении или вставке одного из близнецов сбрасывается состояние обоих.
`store.ts` не менялся.

Тесты: новый `src/editor/remap.test.ts` (6) и 5 тестов в `src/editor/store.test.ts`: удаление первого и второго
близнеца (скрытие, блокировка, выбор, непримененая правка исходника, undo/redo), вставка одинакового соседа с undo,
однозначная правка одного близнеца, сохранение привязки уникального объекта. На прежнем `remap.ts` 6 из них падают.

## Недостающие возможности

| Возможность | Состояние | Кому передать |
|---|---|---|
| Перетаскивание объектов мышью в кадре | Нет; положение правится полями и прижатием к safe zone | Claude Opus 5.5, отдельной задачей после приемки |
| Перенос совпадающих объектов между сценами (match move) | Нет: нет надежного контракта связи объектов | Сначала решение пользователя о контракте, затем Claude |
| Автоматическое слияние своих правок с внешними изменениями `v.html` | Нет; есть выбор «взять с диска» / «сохранить поверх» (проверен через UI) | Codex - оценка необходимости, затем исполнитель |
| Сохранение состояния редактора у близнецов | Нет: при удалении/вставке одного из одинаковых соседей скрытие, блокировка, выбор и путь непримененой правки обоих сбрасываются | Только при запросе пользователя; нужен устойчивый ID объекта |
| Проверка safe zone на всех кадрах ролика | Нет гарантии. Режим «каждый кадр» - шаг 1/30 с от `data-s` каждой сцены (с сеткой рендера совпадает, только если `data-s` кратно 1/30) + ключевые моменты; кадры переходов по умолчанию пропущены, концовка не проверяется, меряется DOM превью, а не mp4 | По запросу пользователя |
| `PUT /videos/:id/section/:n` | Не используется интерфейсом, ищет сцену первым совпадением текста | Удалить или исправить при следующей задаче о сервере |
