# Правила проекта

Ролики для профиля @const_proxima делаются в одном стиле - пресет default (`engine/styles/p5-world.css`, `<body class="p5w">`). Результат проекта - вертикальное видео, исходники сцен - HTML/CSS/JS.

## Начало работы

- Меняй только файлы, необходимые для задачи. Правка отдельного ролика остается в его папке; общий движок меняем только для задачи о движке или когда без этого задачу не решить.
- Перед правкой прочитай нужные документы из карты ниже. Для правок только документации проверяй затронутые правила, пути и примеры; озвучку, рендер и публикацию не запускаем.
- Сохраняй существующие исходники и пользовательские изменения. При отсутствии Git проверяй результат сравнением с копией исходных файлов вне проекта.

## Карта документов и команд

| Дашборд `studio/` (ассеты, демо, правка сцен, запуск сборки) или правки, которые пользователь оставил в нем | [studio/README.md](studio/README.md); правки к сценам лежат в `video/N-slug/work/studio-notes.json` (номер сцены с 0 - текст правки), бэкапы `v.html` - в `work/studio-backups/` |

При расхождении общие правила берем здесь, явно перечисленные исключения серии - в ее документе. Расписание и процедуру публикации читаем в `/post-v`, не дублируем в остальных документах.

Перед работой над серией нужен `video/black-box/SERIES.md`; каркасы собирает `node video/black-box/work/scaffold.mjs`. В текущей копии папка серии отсутствует: до ее восстановления не запускаем этот сценарий и не подменяем правила серии правилами обычных роликов.

## Текст
- Буква «ё/Ё» не используется. Всегда пишем «е/Е» (готово: «Все готово», «еще»).
- Длинные и средние тире (—, –) не используются. Только обычный дефис «-».

## Видео
- Формат Reels 9:16, 1080×1920, 30fps.
- С ролика 91 все сцены только `.white` (#fff) и `.black` (#121212). Подряд на одном фоне - до 2-3 сцен (переход между ними - прокрутка `down`/`up`), затем смена фона. Старые комнаты `.dark` / `.light` / `.electric` / `.candy` (доска, тетрадь, плакат, агитка) не используем.
- Акцент сцены - палитра `pal-<имя>` на сцене (purple, pink, cherry, red, vermilion, orange, amber, yellow, lime, shamrock, green, teal, mint, turquoise, sky, blue, indigo, sapphire, violet, grape: темный цвет - текст, светлый - подложка), разная в соседних сценах. Темные сцены - на обоях из `video/wallpapers` (разные в разных сценах): класс `wall` + `style="--wall:url(../../video/wallpapers/файл.jpg)"`, акцентный компонент по смыслу сцены получает `.glass` (делает `p5-world.css`). Обои в начале ролика (первая темная сцена) каждый раз новые: не те, что в начале предыдущего ролика (посмотреть в `v.html` последних роликов), по кругу по всем файлам `video/wallpapers`. Подсветка - `.mark` или фон `var(--pal-bg)`.
- Палитры Colorhunt (`engine/styles/palettes.mjs`) - только если пользователь прямо попросил другую палитру для ролика.
- Плашки на кадрах нет. Концовка - последняя пустая `<section class="s white pal-* outro" data-s=".." data-e="..+2.5">`, длительность `video.json` включает ее целиком. Белый фон, крупная строка с иконкой Instagram + "const_proxima", ниже иконка подписки + "НЕ ПОДПИСЫВАЙСЯ" без плашки, крупный аватар по центру от нижнего края. Движок вставляет все сам; по умолчанию `video/avatar/bl.png`, `data-ava="mid"` - другой аватар, `data-ava="none"` - без аватара. Аватар концовки - исключение из боковых отступов: занимает ширину кадра, как в референсе.
- Без инфографики: нет «01 / тема», шкал прогресса и «шаг N / M».

## Хук: первые 3 секунды (главное в каждом ролике)
- Зритель решает за 1-3 с. Кадр 0 уже содержательный: ключевой объект сцены виден сразу (не пустой фон, не появление из ничего). Это же и превью ролика.
- К 0.5 с на экране главный вопрос или конфликт крупно (заголовок не меньше 100px), к 2.5 с - ударный момент: огромное слово или число (.num 200px+), акцент камеры, синхронный с ударным словом озвучки. Отдельный SFX не добавляем.
- Хук - противоречие, неожиданное число или узнаваемая бытовая ситуация с подвохом (поиск «диван» находит софу). Не определение, не «сегодня расскажу», не логотип.
- Мем-картинка в хуке - к 1.5 с. Первая фраза голоса начинается не позже 0.2 с.
- В `output/plan.md` хук расписан отдельно: что на кадре 0, 0.5, 1.5, 2.5 с и 2-3 отброшенных варианта. Если в сценарии нет сильного хука - предложить пользователю переписать первую фразу до генерации озвучки.

## Safe zone Reels (1080×1920)
- Типографика (заголовки, текст, подписи, числа) только внутри safe zone текста: отступы сверху 250px, снизу 250px, слева 65px, справа 65px. Рабочая область текста: x 65-1015, y 250-1670 (950×1420px). Сцены верстать через padding `250px 65px 250px`.
- Остальные компоненты (карточки, графики, схемы, код, картинки, 3D) ограничены только боковыми отступами 65px: x 65-1015, по вертикали могут выходить за зону текста.
- За боковые отступы можно выводить только фон и декоративные элементы.

## Движение
- Что-то меняется каждую секунду (проверка `window.p5gaps()`), но спокойно: плавные кривые без отскоков, вращений и тряски, ничего не улетает за экран.
- Кривые без рывка в первом кадре и без отскока (в p5w движок делает сам, `engine/runtime/p5-ease.js`): входы - `glide` (пружина без отскока), камера - `cine`, переходы - smootherstep; не out-cubic/out-quart/out-expo и не пружины с bounce > 0, которые проходят 20-30% пути за первый кадр или перелетают цель. Курсор не мигает. Смена сцены - переходы из списка ниже, на весь путь.
- Планировка (`engine/checks/frame-layout.mjs`, конвейер `video.mjs` запускает сам и пишет замечания в `output/pipeline-review.md`) - заполненность safe zone по сценам, пустота снизу, главный объект, проверка наездов камеры. Норма: заполнено 50%+ (хук 70%+), главный объект 40%+ рабочей области, заголовок 84px+ или огромное число, при наезде текст не на плашке.
- Рывки (`engine/checks/motion-check.py`, конвейер запускает сам после финальной сборки) - покадровый поиск; норма 0, каждый пик посмотреть кадрами (ffmpeg select по номеру кадра, а не -ss).
- Без scale-анимаций текста и карточек (они дергаются при покадровом рендере): входы - сдвиг 24-40px + прозрачность или шторка (clip-path), штамп проявляется шторкой. В мире p5w это делает `preset-dynamic.js` сам; постоянного наезда камеры нет.
- Акцент камеры `data-punch` до 2%, 3-4 раза за ролик, на ударное слово.
- Камера (мир p5w) - в каждой сцене: `data-camk="время цель масштаб [длительность]; ..."`, цель `#id`, `x,y` или `c` (общий план). Камера ведет взгляд по смыслу фразы: наезд на объект, о котором сейчас говорят, панорама к следующему, отъезд. Пока камера близко, остальное приглушается (фокус-наезд), при переезде старая цель гаснет, новая загорается. Наезд 1.08-1.2, движение 0.5-1.4 с, не раньше конца перехода сцены. Движок сам ограничивает масштаб, чтобы цель помещалась в safe zone; цели для наезда верстать не шире 800px. В 3D (облака, предметы) камеру двигать внутри Three.js: `camPath` из `p5-world-three.mjs`.
- Переходы (мир p5w, `data-tr` на сцене). Шторки (`wipe`, `split`, `rise`, `slide`, `diag`, `zoomin`, `zoomout`) и сдвиги вбок (`push`, `pushup`) не используем, движок сам заменяет их старые имена.
  - Тот же фон: `down` (камера плавно едет вниз по полотну, новая сцена снизу) или `up` (вверх), 1.2 с, с легким вертикальным смазом по скорости (движок).
  - Смена фона: `dots` (частицы волной, 0.9 с) - основной; `radial` (круг из `data-wipe="x,y"`), `grow` (новая сцена вырастает карточкой из центра с 60% размера), `shrink` (старая уменьшается карточкой и тает), 1 с; старая или новая сцена под ними в легком размытии.
  - `meme` - мощный зум в мем-картинку старой сцены (`data-wipe="#id картинки"`), размытие, новый кадр проявляется из размытия, 1.2 с. Только после сцены с мем-картинкой.
  - `dissolve` - плавное растворение: новая сцена проявляется поверх старой, 0.9 с, только на том же фоне. `defocus` - расфокусировка: старая уходит в размытие, новая проявляется из размытия, 1.1 с, любой фон.
  - `whip` - быстрый пан вбок со смазом по скорости, 0.6 с, любой фон, `data-wipe="left|right"` - направление. Единственное исключение из запрета сдвигов вбок: не больше раза за ролик, на смене темы мысли.
  - Мягкий уход объекта - `data-exit="t[,d]"` (прозрачность и подъем на 24px, по умолчанию 0.6 с), не совмещать с `data-float`/`data-shake`.
  - Без `data-tr` движок выбирает сам: тот же фон - `down`, другой - `dots`. Переходы чередуем, один и тот же не больше 2 раз подряд.

## Аватары
- Аватар ведущего - вырезанные фото из `video/avatar/cut/` (`bl.png` очки, `br.png` улыбка, `ring.png` серьезный, `mid.png` в костюме; исходники `video/avatar/`, названия файлов - как их ставить). Компонент `<img class="ava ..." src="../video/avatar/cut/файл.png">` из `p5-world.css`:
  - `bl` - снизу слева (x 65), вплотную к низу кадра; `br ring` - вплотную к правому краю и низу; `mid` - по центру, низ на границе safe zone (y 1670); `low ring` - по центру, вплотную к низу кадра.
  - `ring` - белая обводка-стикер 5px (всегда белая). Размер `--ava-h` 480-720px (по умолчанию 660, `mid` 520).
- В хуке аватар выбирается случайно и виден с кадра 0. Дальше - по смыслу фразы (серьезный - на проблему, улыбка - на итог, очки - на совет), не на каждом кадре: 2-3 сцены за ролик, не две подряд, только где низ свободен (текст не перекрывать, контент сдвинуть вбок). Появляется `data-a="rise"` на нужном слове.
- Перед переходом `down`/`up` аватар сам уходит размытием (движок). В концовке аватар ставит движок.
- Вся анимация считается от времени кадра `render(t)`: без таймеров, своих циклов requestAnimationFrame, случайной физики и состояния, накопленного от прошлых кадров. Кадры снимаются параллельно кусками в нескольких Chrome, и кадр с середины ролика должен выглядеть так же, как при проигрывании подряд.
- Библиотеки движка (с ролика 37): Anime.js - морфинг SVG и путь (`p5-anime.js`, только на паузе с перемоткой `seek`), D3 - математика графиков (`p5-d3.js`, без d3-transition), split-type - заголовки по строкам (`data-lines`, `p5-lines.js`). PixiJS, ECharts, SVG.js не используем.

## Типографика
- Математические формулы всегда набирать в LaTeX и рендерить в SVG перед включением в ролик. Не собирать формулы вручную из HTML, Unicode-символов или SVG-примитивов: дроби, индексы, степени, матрицы и математические знаки должен верстать LaTeX-рендерер. Математический шрифт внутри формул - исключение из ограничения шрифтов проекта. Перед рендером видео проверять читаемость, отсутствие обрезания и safe zone формул.
- Только два шрифта: Inter - заголовки и огромные числа `.num` (700-800), ник в концовке (600); Google Sans - параграфы, текст, код, подписи осей и подстрока концовки (400-500). Другие шрифты не подключаем (`engine/styles/fonts-p5.css`). Акцент и шутка - цветом, размером и весом, не отдельным шрифтом.
- letter-spacing только отрицательный. Положительный (2-4px и т.п.) запрещен, в том числе у моно-подписей.
- Uppercase - не больше 2-3 раз за ролик и только по смыслу.
- Иконки Material Symbols Rounded: [слово + иконка] и [иконка + слово], одна-две на сцену.

## Приоритет материалов
- В новых роликах сначала подбираем подходящую по смыслу графику из `video/assets/images/`: иконки `icon-*` для технологий, мемы и предметные изображения для визуальных шуток и объяснений. Новую графику создаем, когда подходящего материала в библиотеке нет.
- Из версий одной картинки используем улучшенную `*-upscaled.png` при сохранении нужной мимики и деталей. Оригинал выбираем, только если восстановление исказило смысл изображения.

## Иконки технологий
- Иконки технологий - отдельные PNG с настоящим прозрачным фоном, предметные фото объемных узнаваемых эмблем. Храним в `video/assets/images/icon-<технология>.png`; в заданиях и планах называем их «иконки».
- Запасные иконки из SVGL - `video/assets/images/icon-<технология>-fallback.svg`, источники указаны в `video/assets/svgl-sources.json`. Основной вариант - предметный PNG; SVG используем, когда PNG отсутствует, плохо читается в сцене или нужен точный плоский логотип. Прозрачность, фирменные цвета и пропорции SVG сохраняем.
- Если в теме или озвучке упоминается технология (например, JavaScript / JS), показываем соответствующую иконку как смысловую графику на первом содержательном упоминании. Появление синхронизируем со словом из `words.json`; одна-две иконки на сцену. Для отсутствующей технологии сначала создаем подходящий PNG в том же стиле.
- Иконка технологии может быть самостоятельным крупным объектом сцены, а не только значком рядом со словом. Вставляем через `<img>` с `object-fit:contain`, сохраняя прозрачность и пропорции, в боковых границах x 65-1015. Фон, обводку и скругление от `.pic` не добавляем; анимация и камера подчиняются общим правилам.
- Фирменные цвета и встроенные буквы эмблемы (JS, TS и т.п.) сохраняем: это исключение из ограничений палитры и шрифтов для содержимого растровой иконки.

## Цвета и эффекты
- Цвета только из переменных `p5-world.css`: `--acc`, `--on`, `--mut`, `--ring`, `--card`, `--pal-fg`, `--pal-bg`. Переменные старых комнат (--board-*, --note-*, --post-*, --agit-*) не используем. Свои hex не придумываем.
- Фоны - wallpapers из `video/wallpapers`: класс `wall`, картинку рисует отдельный `div.bg.wall-bg` с `filter:blur(24px)` и запасом по краям. Blur не ставим на сцену целиком: текст и контент остаются резкими. Белая концовка без wallpaper. Сплошные `.white` / `.black` допустимы по смыслу. Декоративных свечений и градиентного текста нет; блики-градиенты допустимы внутри glass-компонентов.
- Стиль деловой и инженерный (код, таблицы, схемы, 3D-стопки), без «милых» объектов.
- Glass используем выборочно для акцентного компонента по смыслу ролика: главная кнопка, результат операции, выбранная карточка. Включение - явный класс `.glass`. Обычные карточки, кнопки, код и обводки сохраняют базовый стиль; наличие wallpaper само по себе не включает glass. Стекло - дымчатая заливка с верхним бликом, backdrop blur 28px, градиентная фаска 2px, светлая кромка и мягкая тень из `p5-world.css`; работает на любом компоненте набора (`.win.glass`, `.toast.glass`, `.seg.glass`, `.field.glass`, `.btn.glass` - главная кнопка подкрашена акцентом, `.glass.tint` - подкрашенное стекло). Ставим на обоях, на сплошном фоне стекло не читается. Текст без filter:contrast и blur.
- Компоненты минималистичные: ring 2px или плитка `--tile`, без теней. Скругления - переменные `--r` 24px (карточки, окна, панели, код), `--r-in` 16px (вложенные плитки, поля, картинки), `--r-s` 10px (теги, клавиши, флажки); кнопки, чипы, сегменты - капсулы. Свои радиусы не придумываем.
- Набор компонентов (`p5-world.css`, пример `engine/examples/components.html`, таблица - `DESIGN-SYSTEM.md`): `.card`, `.win` (окно с `.win-bar`), `.tile`, `.kpi`, `.list`/`.li`, `.tbl`/`.tr`, `.field`, `.seg`, `.btn` (`.soft`, `.ghost`), `.tag`, `.chip`, `.kbd`, `.toast`, `.tog`/`.chk` (`data-mk`), `.sep`. Интерфейсы в ролике собираем из них, а не верстаем заново; новый общий компонент - в `p5-world.css` в том же стиле.
- 3D - Three.js через `engine/components/p5-world-three.mjs` (`view`, `seg`, `dots`, `edges`, `floor`, `label`, `start`): рендер 2x, матовые материалы, контур чертежа, мягкие тени, точки-диски, HTML-подписи. Заготовка - в комментарии внизу `engine/templates/template.html`, в отдельном `three.mjs` ролика импорт движка - `../../engine/components/p5-world-three.mjs`. Голые MeshStandard без контура и теней, шары-«пузыри» и блестящие материалы не используем.

## Звук
- Текст на экране появляется синхронно с озвучкой (по таймингам слов из `words.json` в папке ролика).
- Голос всегда главный. Музыка тихо, с приглушением (ducking) на фразах.
- Несколько голосов (диалог Alex / Kyle / ...): реплики в `video/N-slug/voices.json`, генерация `python3 engine/audio/tts-multi.py video/N-slug` (ElevenLabs v4, mp3 + общий `words.json`).
- Без звуковых эффектов: только голос и музыка. В `video.json` ролика всегда `"noSfx":true`, `data-punch` без звука, `data-sfx` не ставим.

## Структура
- `video/N-slug/` - все про ролик: `v.html` (исходник), `img/`, `three.mjs`, `субтитры.txt`, озвучка, `words.json`, `work/` (черновики, стоп-кадры, разовые скрипты), `output/` (готовые mp4, обложка, план, ревью, подпись). После публикации `/post-v` удаляет черновики: остаются исходники и `video.mp4`, `cover.jpg`, подписи, `posted.json`.
- `engine/` - только общий движок рендера, файлы роликов сюда не кладем. Новый ролик - копия `engine/templates/template.html` в `video/N-slug/v.html` (мир p5w; строка `<base href="../../engine/">` из шаблона обязательна, свои файлы ролика - через `../video/N-slug/...`). Сборка - `node engine/pipeline/video.mjs N` (см. `engine/README.md`).
- Правила агентов: единый источник - `AGENTS.md` (Codex, Grok, Cursor, Copilot и др.). `CLAUDE.md` - симлинк на него, правим только `AGENTS.md`, сохраняя ссылку. Входные файлы других агентов (`GEMINI.md`, `.grok/GROK.md`) при необходимости тоже создаем как симлинки в рамках соответствующей задачи. Скилл `/new-v` лежит в `.claude/skills/new-v/`, `/post-v` (отложенная публикация в Instagram) - в `.claude/skills/post-v/`; для Codex и других - симлинки в `.agents/skills/`.
