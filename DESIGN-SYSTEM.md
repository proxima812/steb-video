# Дизайн-система роликов @const_proxima

Один стиль для профиля @const_proxima - пресет default. Общие правила: `AGENTS.md`. Порядок работы над роликом и проверки - [PIPELINE.md](PIPELINE.md). Здесь приведены приемы реализации; обязательные ограничения берем из `AGENTS.md`. Для эпизодов 100-109 сначала читаем `video/black-box/SERIES.md` (доступность - см. `AGENTS.md`).

## Структура проекта

```

  styles/                   base.css, fonts-p5.css, пресеты, p5-world.css
  components/               p5-blocks.js, p5-three.mjs, p5-world-three.mjs
  templates/template.html   исходный шаблон нового ролика
  pipeline/                 video.mjs, render.mjs, tex2svg.mjs, помощники
  audio/                    tts.py, tts-multi.py, align.py, p5-audio.mjs
  checks/                   check.mjs, frame-layout.mjs, motion-check.py

video/N-slug/
  v.html, img/, three.mjs    исходник ролика, его картинки и 3D
  субтитры.txt, words.json   сценарий ElevenLabs и тайминги слов
```

Анимации движка: `data-in="12.3"` (время появления), `data-a`, `data-d` (длительность), `data-type` (печать), `data-cnt` (счетчик), `data-strike`. Своя анимация ролика - `window.p5hook=t=>{...}`.

## Пресет default (`engine/styles/fonts-p5.css` + `preset-dynamic.css/.js` поверх `preset-minimal.css/.js`, `engine/templates/template.html`)

- **Как использовать:** новый ролик = копия `engine/templates/template.html` -> `video/N-slug/v.html`, сохраняя `<base href="../../engine/">`. Порядок скриптов важен: `engine.js` -> `preset-dynamic.js` -> `preset-minimal.js` -> `init()`. Своя анимация ролика - `window.p5hook=t=>{...}`.
- **Идея:** удержание без суеты. Что-то меняется каждую секунду: слово по таймингам, состояние объекта, сборка или смена сцены. Проверка ритма - `window.p5gaps(1)` (цель: пусто или только концовка). Камера движется по смысловым ключам `data-camk`, постоянного наезда нет.
- **Движение:** параметры входов, камеры, акцентов и переходов берем из раздела «Движение» в `AGENTS.md`; реализация кривых и фокуса описана ниже в разделе «Кривые, текст и камера». Входы текста и карточек - сдвиг 24-40px с прозрачностью или шторка, без scale. Для p5w используем переходы `down|up|dots|radial|grow|shrink|meme|dissolve|defocus`.
- **Стиль:** деловой и инженерный. Никаких «милых» объектов (звезды, сердечки, пузыри, огонь, вентиляторы-иконки): визуал - код, таблицы, паспорт объекта, схемы, 3D-стопки, сетки ядер. Иконки Material Symbols только рядом со словами, одна-две на сцену. Предметные иконки технологий - по разделу «Иконки технологий» в `AGENTS.md`.
- **Без инфографики:** нет «01 / тема», шкал прогресса, строки бита. Плашки на кадрах нет: крупный профиль с иконкой Instagram, ниже «НЕ ПОДПИСЫВАЙСЯ» с иконкой, аватар по центру от нижнего края на белом фоне - только в концовке (`section.outro`, последняя сцена 2.5 с, заполняет `engine.js`).
- **Пресет default (с ролика 36):** `p5-world.css` + `<body class="p5w">` + `p5-world-three.mjs`. С ролика 37 движок мира: кривые `p5-ease.js`, Anime.js `p5-anime.js`, D3 `p5-d3.js`, split-type `p5-lines.js` (подключение - `engine/templates/template.html`).
- **Палитры Colorhunt (по просьбе):** паки с colorhunt.co, случайные по теме ролика: `node engine/styles/palettes.mjs N "теги" --no-red` (теги Colorhunt: space, night, sea, nature, coffee, retro, cold, warm ...). Скрипт берет популярные палитры по тегам, детерминированно перемешивает (seed = номер ролика), чередует темные и светлые, из каждой палитры делает тему: фон - крайний по яркости цвет, текст - контрастный (не ниже 7:1), акцент - самый насыщенный читаемый цвет. Результат `engine/palette-N.css`, выбор в `video/N-slug/palette.json` (повторный запуск берет его, `--force` - выбрать заново).
- **Фоны и цвет (с ролика 91):** сцены только `.white` (#fff) и `.black` (#121212), подряд на одном фоне до 2-3 сцен, затем смена; wallpapers из `video/wallpapers` ставим через `wall` и отдельный размытый `div.bg.wall-bg`, glass включается только у смыслового акцента классом `.glass`. Акцент - палитра `pal-<имя>`, разная в соседних сценах. Цвета только переменные `p5-world.css` (`--acc`, `--on`, `--mut`, `--ring`, `--card`, `--pal-fg`, `--pal-bg`). Декоративных свечений, размытых кругов и градиентного текста нет; блики-градиенты внутри glass допустимы.
- **Старые темы:** `.dark` / `.light` / `.electric` / `.candy` и темы Tailwind (vercel, mobbin, amie) не используем в новых сценах. Наличие класса в старом исходнике или шаблоне не делает его актуальным правилом.
- **Шрифты:** Inter - заголовки и числа 700-800 (`.h`, `.h2`, `.h3`, `.num`), Google Sans - текст, код, подписи 400-500. Математический шрифт внутри LaTeX-SVG - исключение. Трекинг только отрицательный.
- **Иконки:** Material Symbols Rounded, filled (fonts.google.com/icons). `<i class="mi">memory</i>`; [слово + иконка] `<span class="iw">слово <i class="mi">memory</i></span>`, [иконка + слово] `<span class="iw"><i class="mi">memory</i> слово</span>`; `.ib` - иконка в плитке, `.ib.solid` - залитая, `.ib2` - второй акцент.
- **Атрибуты p5w:** сцена - `data-tr`, `data-wipe`, `data-camk`, `data-punch="t:.02"` без звука; входы - `data-in`, `data-a`, `data-d`; слова - `data-lines` или `data-wd-times`. Времена берем из `words.json` (исключение - серия без голоса). Дополнительные атрибуты старых пресетов не обходят ограничения p5w на масштаб, вращение, тряску и звук.
- **UI и курсор** (сцены с интерфейсом, терминалом, формой):
  - курсор ведет действие по цепочке: наведение -> реакция цели (hover) -> клик -> смена состояния -> читаемый результат. Не летает над пассивным экраном. Путь 0.6-0.9с по плавной дуге, перед кликом короткая пауза наведения, клик - легкое сжатие 0.92 и возврат;
  - точка попадания - кончик стрелки, а не центр иконки. Курсор не закрывает подпись кнопки, результат и числа;
  - состояния причинны: hover -> pressed -> processing -> success. Успех не раньше, чем закончился процесс; прогресс-бар, процент и график одной операции идут синхронно;
  - drag: точка захвата фиксирована, карточка приподнимается сдвигом и тенью без изменения масштаба, затем идет по дуге, слот подсвечивается, при drop мягко садится. Соседи реагируют после события, без пружин;
  - один и тот же «экран» живет через несколько сцен: те же данные, радиусы, позиции. Результат вырастает из элемента, который его вызвал, без двойников при переходе;
  - выделять в действии 1-3 главных контрола, остальное фоном. Демо-данные не выдавать за реальные метрики сервиса.
  - реализация - `engine/runtime/p5-motion.js` (подключен в шаблоне), пример `engine/examples/motion-demo.html`. Курсор: у сцены `data-cur="t #id; t #btn click; t #chip drag #slot; t hide"` (последнее число ключа - длительность пути, по умолчанию .75 с). Цель клика получает `--hover`, `--press`, `--done` (плавно за .35 с) и класс `.cur-done`, по ним верстаем реакцию кнопки. Слот - копия чипа в целевой карточке: до drop пунктир, при drop заполняется. Места в макете чип и слот держат все время;
  - растущий блок (чат, флоу, список карточек) - `data-grow="y"` у контейнера: видимая часть стоит по центру и плавно съезжает с каждым новым ребенком, к концу сдвиг 0;
  - чат - `.chat` с пузырями `.bub.me` (справа, подложка палитры) и `.bub.bot` (слева, карточка), подпись автора `.bub-who`; пузыри и карточки входят `data-a="blur"` (из размытия 8px со сдвигом 24px);
  - схема-дерево и флоу - `data-link="#from"` у карточки: пунктирная кривая от `#from` рисуется за .45 с до появления карточки (`data-in`), карточка встает на конце линии.
- **Огромное число в хуке:** слот-роллер `<span class="num roll cells" data-roll="t0,t1,3000[,from]">` - разряды крутятся барабанами со смазом по скорости и встают слева направо к t1; на кадре 0 уже видны цифры from. Для «ударного числа» к 2.5 с ставим t1 на ударное слово озвучки. Плавный счет без барабанов - `data-cnt`.
- **Звук:** только голос и музыка с ducking, звуковых эффектов нет (`"noSfx":true` в `video.json`, `data-punch` без звука, `data-sfx` не ставим).
- **Базовый слой анимаций** (`preset-minimal.js`, бывший пресет №4; все от t; с `<body data-txt="blur">` слова текста поднимаются на 3px из размытия 4px, штатное размытие входа текста). Ниже справка для чтения старых сцен: атрибуты с scale, tilt и перемещением между сценами не переносим в новые p5w-сцены. Новые входы и камеру делаем по правилам выше:
  - `data-wd="t0,шаг"` + `data-wd-times="t1,t2,.."` - слова выезжают из маски строки по таймингам озвучки (с `data-txt="blur"` - подъем на 3px из размытия). Для новых заголовков - `data-lines` (split-type, `p5-lines.js`).
  - `.hero` + `data-p4-path="t:якорь:scale;.."` - главный объект (формула, число) перелетает между якорями `<i class="anc" data-anchor>`, в том числе из сцены в сцену; цвет берет от фона.
  - `data-p4-view="t0,d"` + `data-p4-from="x,y,scale"` + `data-p4-origin` - камера: деталь -> общий план (scale до ~1.16, smoothstep).
  - `data-p4-build="t0,d,шаг"` - сборка карточки слоями; `data-p4-exit="t0,d"` - мягкий выход (-18px, .98).
  - `data-p4-swap="t0,d"` - замена значения в неподвижной маске (вместо перебора `data-cnt`).
  - `data-draw="t0,t1"` - схема/график по шагам: ось -> кривая -> заливка; `data-tilt="t0,deg"` - выпрямление панели (8-12°).
  - Собственный зум сцены движка в пресете выключен.
- **Компоненты:** `.plot` - SVG-графики (`.area` - заливка под кривой); карточки, чипы, код и изображения описаны ниже в разделе «Компоненты сцен».

## Формулы

Формулы набираем в LaTeX, рендерим в SVG до сборки ролика:

```html
<div class="tex" id="formula"><!--tex y=Wx+b--><!--/tex--></div>
```

```bash
node engine/pipeline/tex2svg.mjs video/N-slug
```

После изменения LaTeX команду запускаем снова. Исходник сохраняется в комментарии, SVG наследует `currentColor` и размер контейнера. Для цели камеры внутри формулы - `\cssId{id}{...}`. Перед рендером проверяем читаемость, отсутствие обрезания и safe zone. Старую ручную верстку `.fx` из HTML, Unicode, индексов и дробей не используем.

## Кривые, текст и камера

Без scale у отдельных текстов и карточек: входы сдвиг 24-40px + прозрачность, штамп - шторка. Масштаб есть только у камеры сцены.
Кривые (`engine/runtime/p5-ease.js`, с ролика 37), все без рывка в первом кадре и без отскока: `glide` - пружина без отскока 3-го порядка (как spring({bounce:0}) в Motion: половина пути к 30% времени, длинный мягкий доезд) для входов элементов и слов, 0.8 / 0.7 с; `cine` - cubic-bezier(.45,0,.2,1) для камеры, рисования линий и счетчиков; `soft` - smootherstep для переходов сцен (шторка через весь кадр не терпит крутых кривых); `quint` / `expo` - inOutQuint / inOutExpo из Anime.js для длинных пролетов. Своя кривая - `data-ease` у элемента или 5-е поле ключа `data-camk`; `?ease=soft` или `<body data-ease="soft">` - все по-старому.
Заголовки - `data-lines="t1,t2,.."` (`p5-lines.js`, split-type): текст делится по реальным строкам, строка выезжает из маски на своем первом слове. С `<body data-txt="blur">` (по умолчанию в `template.html` для новых роликов) каждое слово в свое время поднимается на 3px из размытия 4px по кривой cubic-bezier(.7,.1,.5,.9) (`P5T.ease`), без маски; длинную фразу озвучки не выводим целиком - короткий заголовок + смысловая графика (пример `engine/examples/text-blur-demo.html`). Морфинг SVG и движение по пути - Anime.js (`p5-anime.js`: `data-morph`, `data-mpath`, `P5A.tl`), анимации на паузе, движок перематывает их к t. Графики - D3 (`p5-d3.js`: `P5D3.plot`, шкалы, `fn`, `tangent`, `axes`), без d3-transition.
Камера `data-camk`: наезд 1.08-1.2 на объект фразы, панорама, отъезд; фокус-наезд приглушает остальное до 6% (`data-camdim=".45"` у сцены или body - мягче, если произносимый текст вне цели); цель всегда в safe zone (ограничение в движке); старт не раньше конца перехода. 3D-камера - `camPath`.
Переходы (`data-tr`, без шторок и сдвигов вбок): тот же фон - `down` / `up` (камера едет по полотну со смазом по скорости до 10px, 1.2 с); смена фона - `dots` (частицы, 0.9 с), `radial` (круг, 1 с), `grow` / `shrink` (сцена-карточка растет с 60% или уменьшается до 65% и тает, 1 с; сцена под ней в размытии до 8-10px), `meme` (зум в мем-картинку + размытие, 1.2 с); `dissolve` (растворение на том же фоне, 0.9 с), `defocus` (расфокусировка, 1.1 с), `whip` (пан вбок со смазом, 0.6 с, не больше раза за ролик). Уход объекта - `data-exit="t[,d]"`. Длительности - таблица `TRD` в `runtime/preset-dynamic.js` (`window.P5TR`, ее читает `checks/check.mjs`; таблицы студии `studio/src/editor/timing.ts` и `camera.ts` держим в синхроне). Камера `data-camk` ждет конца перехода своей сцены. Демонстрация и проверка концов переходов: `engine/examples/transitions-new.html`, `cd engine && node checks/transition-endpoints.mjs`. Аватары ведущего - `.ava` (раздел «Аватары» в `AGENTS.md`). Проверки: `frame-layout.mjs` (планировка и кадрирование), `motion-check.py` (рывки, норма 0).

Для `dots` атрибут входящей сцены `data-dots-dir="right|up|left|down"` задает направление волны: слева направо, снизу вверх, справа налево, сверху вниз. Пример: `<section data-tr="dots" data-dots-dir="up" ...>`. Закрытие старой сцены и раскрытие новой идут в одном направлении. Без атрибута или при неизвестном значении сохраняется прежняя диагональ; длительность 0.9 с.

## 3D

`p5-world-three.mjs`: рендер 2x, RoomEnvironment, мягкие тени на ShadowMaterial-пол, матовые материалы (roughness .78), контур чертежа Line2 цветом текста или фона, точки-диски шейдером, толстые отрезки для осей и связей, HTML-ярлыки по проекции. Камера в изометрии (ortho) для предметов, перспектива 30° для облаков. Вращения только медленный параллакс облака (±0.12 рад).

## Компоненты сцен

Один стиль: ring 2px или плитка `--tile`, без теней; радиусы `--r` 24px / `--r-in` 16px / `--r-s` 10px, кнопки, чипы, сегменты и теги - капсулы. Акцент - `.on` (палитра), стекло - `+ .glass`. Все компоненты на белом, черном и на обоях со стеклом - `engine/examples/components.html`.

| компонент | разметка | когда |
| - | - | - |
| карточка | `.card` (`.box` - то же) | блок с текстом, сравнение |
| окно | `.win > .win-bar` (три `<i></i>`, `<b>` заголовок) `+ .win-body` | интерфейс, браузер, приложение |
| плитка | `.tile`, `.tile.on` | вложенный блок, ячейка сетки, выбранный вариант |
| показатель | `.kpi > .num + .kpi-l` (часто `.card.kpi`) | число с подписью |
| список | `.list > .li` (`.ib` иконка, текст, `.li-m` справа), `.li.on` | файлы, результаты, варианты |
| таблица | `.tbl style="--cols:1fr 1fr 160px" > .tr` (`.th` шапка, `.on` строка, `.r` число справа) | сравнение значений |
| поле | `.field > .mi` + текст или `.ph` + `.caret`; `.field.on` - фокус | поиск, ввод (каретка не мигает) |
| сегменты | `.seg > span`, `span.on` | выбор режима, фильтр |
| кнопка | `.btn`, `.btn.soft`, `.btn.ghost` | действие; главная - `.btn`, с курсором `data-cur` |
| тег, чип | `.tag`, `.tag.on`; `.chip`, `.chip.on` | мелкая подпись; крупный ярлык |
| клавиша | `.kbd` внутри текста | сочетания клавиш |
| уведомление | `.toast > .ib + div(b, span) + .tag` | результат, событие |
| тумблер, флажок | `<i class="tog" data-mk="t">`, `<i class="chk" data-mk="t">` | включаются за .55 с от `t` |
| код, картинка | `.code5`, `.pic` (мем, 200-250px), `.stampx`, `.mark` | |
| разделитель | `.sep` | |

Стекло - на 1-2 компонентах сцены на обоях: окно приложения, уведомление, поле поиска, сегменты, главная кнопка (`.btn.glass` подкрашена акцентом), выбранная плитка (`.tile.on.glass`). Остальное в той же сцене - обычные `.card` / `.tile`: контраст стекла и плотной карточки и есть акцент. На сплошном `.white` / `.black` стекло почти не видно, там его не ставим.

## Safe zone и glass

На кадре 1080×1920 отступы текста: сверху и снизу 250px, по бокам 65px. Рабочая область x 65-1015, y 250-1670 (950×1420). CSS-переменные `--sz-t`, `--sz-b`, `--sz-x` в `engine/styles/base.css` управляют версткой, камерой и проверками.

Wallpaper задается на сцене: `style="--wall:url(../../video/wallpapers/файл.jpg)"`. URL переменной разрешается относительно `engine/styles/p5-world.css`, где используется фон. Движок вставляет `div.bg.wall-bg`; размытие только у него, по умолчанию 24px (`--wall-blur`).

Glass включается только явно добавленным `.glass` у акцентного компонента: результата, выбранной карточки или главной кнопки. Примеры: `.card.glass`, `.chip.glass`, `button.glass`. Остальные компоненты и обводки остаются обычными; wallpaper не включает glass автоматически. Заливка и ring зависят от светлой/темной сцены (`--glass-fill`, `--glass-ring`, `--glass-shadow`); поверхность: дымчатая заливка с верхним бликом (`--glass-sheen`), backdrop blur 28px с насыщенностью 1.6 (`--glass-blur`), градиентная фаска 2px через `::before` (светлая сверху слева, `--glass-edge`), светлая верхняя кромка и мягкая тень снизу. `.glass.tint` и `.on.glass` подкрашены акцентом. Внутри стекла плитки, поля и разделители сами становятся полупрозрачными. Радиус берется у компонента (по умолчанию `--r`). Контраст и размытие текста не меняем.

Концовка: белая сцена 2.5 с; ник с иконкой на y 650, подстрока «НЕ ПОДПИСЫВАЙСЯ» с иконкой на y 805, аватар `bl.png` по центру, на всю ширину от нижнего края. Ник - Inter 600, подстрока - Google Sans 400. `data-ava="none"` сохраняет вариант без аватара.

## Композиционная режиссура (Scene IR)

Дополнительный контракт и примеры - `output/design-system.md`, `output/motion-system.md`,
`output/camera-system.md`. Пять opt-in компоновок вынесены в
`engine/styles/scene-compositions.css`: hero, diagram, interface, data, cinematic.
Они задают расположение, не заменяя существующие компоненты и палитры.

Scene IR требует объяснить смысл движения и выбрать главный объект; одинаковые
композиции подряд получают предупреждение. `data-camfit="safe"` с подключенным
`runtime/p5-camera.js` защищает все цели camk и элементы с `data-camera-keep` + id.
Часть запрошенного наезда может быть ограничена ради читаемости. Это режим для
статической базовой геометрии; data-grow, 3D и движущиеся SVG требуют отдельных проверок.
